# Security Policy

## Supported Versions

DevVault is currently under active development.

At this stage, security fixes will generally be applied to the latest version available on the `main` branch.

Once stable releases are established, this section will be updated to clearly define supported versions.

## Reporting a Vulnerability

Please do **not** report security vulnerabilities through public GitHub issues.

If you discover a potential security vulnerability in DevVault, please report it privately through GitHub's security reporting features when available.

If private vulnerability reporting is not yet enabled, please contact the project maintainer through the DevVault GitHub repository and avoid publicly disclosing sensitive details.

### Please Include

When reporting a security issue, provide:

- A description of the vulnerability
- Steps to reproduce the issue
- The potential impact
- Affected component or version
- Any relevant logs, screenshots, or proof of concept
- Suggested mitigation, if available

Please provide enough information for the maintainers to reproduce and investigate the issue.

## Responsible Disclosure

We ask security researchers and contributors to give the maintainers reasonable time to investigate and address a vulnerability before publicly disclosing it.

We appreciate responsible security research and will make a reasonable effort to acknowledge valid security reports.

## Security Development Practices

As DevVault develops, the project will adopt security practices including:

- Secure password hashing
- Authentication and authorization controls
- Input validation
- Protection against common web vulnerabilities
- Dependency updates
- Automated security checks
- Secure handling of sensitive configuration
- Regular dependency and code reviews

Security requirements may evolve as the project grows.

## Scope

This policy applies to the DevVault source code and officially maintained project infrastructure.

Third-party services and dependencies are subject to their own security policies.

Thank you for helping keep DevVault secure.
