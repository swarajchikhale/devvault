# Code of Conduct

## Our Pledge

We are committed to making participation in DevVault a welcoming, respectful, and inclusive experience for everyone.

We welcome contributions from people of all backgrounds and experience levels.

## Expected Behavior

Contributors and community members are expected to:

- Be respectful and professional.
- Communicate constructively.
- Be open to different opinions and approaches.
- Give and receive constructive feedback.
- Focus on what is best for the project and its community.
- Help create a welcoming environment for new contributors.

## Unacceptable Behavior

The following behavior is not acceptable:

- Harassment or discrimination.
- Personal attacks or insults.
- Trolling or deliberately disruptive behavior.
- Publishing someone's private information without permission.
- Sexualized language or unwanted sexual attention.
- Threats or intimidation.
- Any other behavior that would reasonably be considered inappropriate in a professional open-source community.

## Reporting Problems

If you experience or witness unacceptable behavior, please report it to the project maintainers.

For sensitive matters, use the contact information provided in `SECURITY.md` or contact the project maintainer directly through the project's GitHub repository.

Please include enough information for the maintainers to understand and investigate the situation.

Reports will be handled as respectfully and confidentially as reasonably possible.

## Enforcement

Project maintainers may take appropriate action in response to unacceptable behavior, including:

- Asking someone to stop the behavior.
- Removing inappropriate comments or content.
- Temporarily restricting participation.
- Removing someone from the project or community in serious cases.

Maintainers will use their best judgment when handling incidents.

## Scope

This Code of Conduct applies to project spaces and interactions related to DevVault, including:

- GitHub issues
- Pull requests
- Code reviews
- Discussions
- Project documentation
- Other official DevVault community spaces

## Questions

If you have questions about this Code of Conduct, please open a GitHub discussion or contact the project maintainers.

Thank you for helping make DevVault a respectful and welcoming open-source project.
